🌾 AnnaSetu (अन्नसेतु)Smart Agricultural Procurement & Zero-Waste Surplus Food Redistribution PlatformAnnaSetu is a dual-impact AgTech and social welfare platform built to solve two critical systemic challenges: agricultural price exploitation of smallholder farmers and commercial food waste.🚀 Key Features1. 👨‍🌾 Agri-Procurement & Farmer Pocket LedgerLive Mandi & MSP Benchmarks: Direct comparison between Government Minimum Support Prices (MSP) and local market procurement rates across districts.Direct Harvest Listings: Farmers can log harvest yields (crop type, quantity in quintals, expected rates) into an integrated digital ledger.Instant Order Matching: Connects pooled village cluster harvests directly with institutional buyers to bypass middleman markups.2. 🤝 Zero-Waste Surplus Food BridgeCommercial Kitchen Listings: Hotels, canteens, banquet halls, and supermarkets broadcast safe edible surplus food batches.Immediate NGO Reservation: Real-time location-based directory allowing verified shelters and community networks to claim meal pickups within safe freshness windows (under 3 hours).3. 🚚 Smart Match & Dynamic Transit SimulatorCorridor Route Optimization: Interactive simulation engine matching harvest cluster origins to urban distribution depots.Digital Agricultural Transit Pass: Instant generation of digital e-Way passes with cryptographic verification hashes and QR validation for fast-track green corridor transit.4. 📊 Admin Oversight & Support SystemsReal-time Analytics Visualizations: Visual breakdown of procurement volumes, food rescue efficiency (94.8%+ target), and farmer income uplift (+18.2%).Grievance Resolution Desk: Integrated support ticketing system for payment settlement and weight verification queries.🛠️ Tech Stack & ArchitectureCurrent Client PlatformUI/UX Framework: Pure HTML5, ES6 JavaScript, and Tailwind CSS.Iconography: Lucide Icons.Architecture: Responsive Single-Page Application (SPA) with dynamic tab switching and real-time client-side state synchronization.Recommended Backend Stack (Target Integration)Framework: Node.js (Express) or Python (FastAPI).Database: PostgreSQL with PostGIS extension (for spatial district routing) or MongoDB.External APIs: Government Agmarknet API (Mandi prices), Twilio/WhatsApp Business API (SMS alerts), and Razorpay/UPI (Instant payments).📂 File Structure├── index.html        # Main Single-Page Application UI & dynamic JavaScript application logic
└── README.md         # Documentation & API Integration Guide
